## Committee coverage

A fresh local combined demo persisted 70 decisions: 60 committee replay decisions plus ten decisions across the two five-event paper sessions. Across 140 asset-decisions, technical produced 69 positive, 65 negative and six neutral recommendations. Each of the other five agent types returned 140 insufficient-data recommendations.

- Sentiment: no eligible cached news feature.
- Quant: no unique original forecast for the decision session; merely supplying a model ID does not create matching-date forecasts.
- Strategy: no existing selected M7 strategy configured into the committee request.
- Fundamental and macro: no genuine point-in-time statements/vintages configured; these adapters explicitly abstain in the current replay engine.

The technical explanation previously rendered a value such as `0.009639496694523464` directly from stored prose. The display now rounds only recognized technical/sentiment heuristic explanations to six significant digits, preserves tiny nonzero values, and keeps the original full explanation in the evidence inspector. Signal/strength calculations and stored records do not change.

**Separate follow-up:** build an explicitly labeled evidence-rich synthetic fixture using actual cached-news feature generators, eligible matching-date forecasts and an existing M7 selection. Test clock eligibility, differing agent assessments, dependency grouping and independent risk/fill vetoes. Fundamental/macro participation would require additional adapter work. This is beyond a focused presentation PR; no missing agent vote is overridden or fabricated here, and no profitability target is introduced.
