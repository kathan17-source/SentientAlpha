# Dashboard screenshots

## Screenshot provenance

These are direct, unedited 1600 × 1100 Chromium viewport captures of the existing offline synthetic demo. The [capture run](https://github.com/kathan17-source/SentientAlpha/actions/runs/40453801414) rendered them on 2026-10-27 from revision `61b8fd0`, using a new database generated by `scripts/release_demo.py`. No provider inputs, credentials, model downloads, mocked responses, injected page content or AI images were used.

The captures assert synthetic-only coverage, backend connection, version, simulation warnings and a primary heading. Paper selects the normal session; the separate PAUSED zero-fill veto remains independently tested. The images were visually checked for credentials, personal/provider content and misleading performance claims before inclusion. Displayed returns are synthetic software output, not historical market performance or deployment evidence.

## Reproduce authorized captures

Follow [DEMO.md](../DEMO.md) and start the API and production frontend against a **new synthetic demo database**. On a permitted browser host, run:

```sh
npm --prefix frontend run test:e2e -- portfolio.spec.ts
```

`PORTFOLIO_SCREENSHOTS` optionally chooses an output directory; otherwise files stay in ignored Playwright results. CI retains only these four named PNGs after successful checks for three days, not databases, logs, traces, environments or caches. Never run this capture against genuine-provider data. See [committee coverage and demo behavior](../DEMO.md#committee-coverage), [verification](VERIFICATION.md) and [LICENSE](../LICENSE).
